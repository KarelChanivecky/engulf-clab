# engulf-clab-license-pool-lib

Framework-neutral pool-manager and selector contracts for license-pool
integrations. It owns the reusable registered-pool state manager and
allocation-handoff contract; the default selector implementation remains in
the product plugin. The default Engulf callbacks remain in
[`engulf-clab-license-pool`](../engulf-clab-license-pool/README.md).
